1. Difference Between font-style and font-weight


font-style
p{
    font-style: italic;
}

👉 Makes text italic.

font-weight
p{
    font-weight: bold;
}

👉 Makes text bold.

Interview Answer

font-style controls italic text, while font-weight controls the thickness (boldness) of text.

2. Why do we write multiple fonts?

Example:

body{
    font-family: Arial, Helvetica, sans-serif;
}

3.Tricky Question

3.Why not write only Arial?

Answer

If Arial is not available on the user's device, the browser tries Helvetica.

If Helvetica is also unavailable, it uses a generic sans-serif font.

This is called a font fallback.

4. Is font-weight: bold same as font-weight: 700?
Answer

Usually yes.

font-weight: bold;

≈

font-weight: 700;

Both produce bold text in most fonts.

12.What is the difference between px, em, and rem?"

👉 px is fixed, em depends on the parent element, and rem depends on the root (html) element.

px  → Fixed size

em  → Parent size

rem → Root(html) size
