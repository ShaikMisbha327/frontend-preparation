🔹 1. font-family
Definition

The font-family property is used to change the font style of text.

Example
body{
    font-family: Arial, sans-serif;
}

Common Fonts

Arial
Verdana
Tahoma
Times New Roman
Georgia
Interview Answer

"The font-family property is used to specify the font of text."

🔹 2. font-size
Definition

The font-size property is used to change the size of text.

Example
h1{
    font-size: 36px;
}
Interview Answer

"The font-size property is used to control the size of text."

🔹 3. font-weight
Definition

The font-weight property is used to make text bold or lighter.

Values
normal
bold
100
200
300
400
500
600
700
800
900
Example
h1{
    font-weight: bold;
}
Interview Answer

"The font-weight property controls the thickness of text."

🔹 4. font-style
Definition

The font-style property is used to make text italic.

Values
normal
italic
Example
p{
    font-style: italic;
}
Interview Answer

"The font-style property is used to make text italic or normal."

🧠 Memory Trick
font-family → Font type
font-size   → Text size
font-weight → Boldness
font-style  → Italic
