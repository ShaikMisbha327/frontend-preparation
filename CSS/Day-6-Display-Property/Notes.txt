Display Property:

The display property controls how an HTML element is displayed on a webpage.

It decides:

1.Whether an element starts on a new line.
2.Whether it takes full width or only the required width.
3.Whether you can set width and height.
4.Whether the element is visible or hidden.

1. What is the Display Property?

Definition:-

The display property specifies how an HTML element is displayed on a webpage.

Syntax

display: value;

Example
h1{
    display: block;
}

1.Interview Answer

**The display property controls how an HTML element is displayed and how it behaves in the layout.

2. Types of Display Property

1.block
2.inline
3.inline-block
4.none


3. display: block

Definition

A block element:

1.Starts on a new line.
2.Takes the full available width.
3.You can apply width and height.

ex:
HTML

<div>Frontend Developer</div>
<div>Full Stack Developer</div>

css:

div{
    display: block;
    background-color: lightblue;
}

output:
Frontend Developer

Full Stack Developer


Each div starts on a new line.

Common Block Elements
<div>
<h1> to <h6>
<p>
<section>
<header>
<footer>

Interview Answer

A block element starts on a new line and takes the full available width.


4. display: inline

Definition:

An inline element:

1.Does not start on a new line.
2.Takes only the width it needs.
3.Width and height do not work.

ex:
HTML

<span>HTML</span>
<span>CSS</span>
<span>JavaScript</span>

css

span{
    display: inline;
    background-color: lightgreen;
}

output:
HTML CSS JavaScript

All appear on the same line.

Common Inline Elements
<span>
<a>
<strong>
<em>
<label>

Interview Answer

An inline element takes only the required width and stays on the same line.


5. display: inline-block
Definition

An inline-block element:

1.Stays on the same line like an inline element.
2.Allows width and height like a block element.

It combines the advantages of both.
ex:
html

<div class="box">HTML</div>
<div class="box">CSS</div>
<div class="box">JavaScript</div>

css

.box{
    display: inline-block;
    width: 150px;
    height: 80px;
    background-color: skyblue;
    text-align: center;
}

output:

Three boxes appear on the same line, each with its own width and height.

Interview Answer

inline-block keeps elements on the same line while allowing width and height to be set.


6. display: none

Definition:

1.The element is completely removed from the webpage layout.

2.It is not displayed and does not occupy any space.

ex:
html

<p>This paragraph is visible.</p>

<p class="hide">
    This paragraph is hidden.
</p>

css:

.hide{
    display: none;
}

Output:
Only the first paragraph is visible.

Interview Answer

display: none completely hides an element and removes it from the page layout.
